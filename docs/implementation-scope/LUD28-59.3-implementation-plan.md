## 🚀 Implementierungsreihenfolge

### Prioritäten-Strategie

1. **Abhängigkeitsbasiert:** Entities ohne FK zuerst (z.B. `User`, `Category`)
2. **Domänen-orientiert:** Zusammenhängende Entities gemeinsam (z.B. Auth → Terminals → Speech)
3. **Test-freundlich:** Entities mit wenigen Relations zuerst für schnelle Validierung

### Implementierungsschritte

#### Schritt 1: User-Entity erstellen

```typescript
// backend/nest-app/src/modules/auth/entities/user.entity.ts

import { Entity, PrimaryGeneratedColumn, Column, CreateDateColumn, UpdateDateColumn, OneToOne, OneToMany, Index } from 'typeorm';
import { UserRights } from './user-rights.entity';
import { UserAllowedTerminal } from './user-allowed-terminal.entity';

@Entity('users')
@Index('ix_users__username', ['username'])
@Index('ix_users__email', ['email'])
export class User {
  @PrimaryGeneratedColumn('uuid', { name: 'id' })
  id: string;

  @Column({ type: 'varchar', length: 255, unique: true, name: 'username' })
  username: string;

  @Column({ type: 'varchar', length: 255, unique: true, name: 'email' })
  email: string;

  @Column({ type: 'varchar', length: 255, name: 'password_hash' })
  passwordHash: string;

  @Column({ type: 'varchar', length: 255, nullable: true, name: 'full_name' })
  fullName: string | null;

  @Column({ type: 'boolean', default: true, name: 'is_active' })
  isActive: boolean;

  @CreateDateColumn({ type: 'timestamp', name: 'created_at' })
  createdAt: Date;

  @UpdateDateColumn({ type: 'timestamp', name: 'updated_at' })
  updatedAt: Date;

  // Relations
  @OneToOne(() => UserRights, (userRights) => userRights.user)
  rights: UserRights;

  @OneToMany(() => UserAllowedTerminal, (uat) => uat.user)
  allowedTerminals: UserAllowedTerminal[];
}
```

#### Schritt 2: UserRights-Entity erstellen

```typescript
// backend/nest-app/src/modules/auth/entities/user-rights.entity.ts

import { Entity, PrimaryGeneratedColumn, Column, OneToOne, JoinColumn, CreateDateColumn, UpdateDateColumn, Index } from 'typeorm';
import { User } from './user.entity';

@Entity('user_rights')
@Index('uq_user_rights__user_id', ['userId'], { unique: true })
export class UserRights {
  @PrimaryGeneratedColumn('uuid', { name: 'id' })
  id: string;

  @Column({ type: 'uuid', unique: true, name: 'user_id' })
  @Index('fk_user_rights__users__user_id')
  userId: string;

  @Column({ type: 'boolean', default: false, name: 'can_use_speech' })
  canUseSpeech: boolean;

  @Column({ type: 'boolean', default: false, name: 'can_admin' })
  canAdmin: boolean;

  @Column({ type: 'boolean', default: false, name: 'can_configure_llm' })
  canConfigureLlm: boolean;

  @Column({ type: 'boolean', default: false, name: 'can_view_logs' })
  canViewLogs: boolean;

  @Column({ type: 'boolean', default: false, name: 'can_manage_terminals' })
  canManageTerminals: boolean;

  @CreateDateColumn({ type: 'timestamp', name: 'created_at' })
  createdAt: Date;

  @UpdateDateColumn({ type: 'timestamp', name: 'updated_at' })
  updatedAt: Date;

  // Relations
  @OneToOne(() => User, (user) => user.rights)
  @JoinColumn({ 
    name: 'user_id', 
    foreignKeyConstraintName: 'fk_user_rights__users__user_id' 
  })
  user: User;
}
```

#### Schritt 3: UserAllowedTerminal-Entity erstellen

```typescript
// backend/nest-app/src/modules/auth/entities/user-allowed-terminal.entity.ts

import { Entity, PrimaryColumn, ManyToOne, JoinColumn, CreateDateColumn } from 'typeorm';
import { User } from './user.entity';
import { AppTerminal } from '../../terminals/entities/app-terminal.entity';

@Entity('user_allowed_terminals')
export class UserAllowedTerminal {
  @PrimaryColumn({ type: 'uuid', name: 'user_id' })
  userId: string;

  @PrimaryColumn({ type: 'uuid', name: 'terminal_id' })
  terminalId: string;

  @CreateDateColumn({ type: 'timestamp', name: 'created_at' })
  createdAt: Date;

  // Relations
  @ManyToOne(() => User, (user) => user.allowedTerminals, { onDelete: 'CASCADE' })
  @JoinColumn({ 
    name: 'user_id', 
    foreignKeyConstraintName: 'fk_user_allowed_terminals__users__user_id' 
  })
  user: User;

  @ManyToOne(() => AppTerminal, (terminal) => terminal.allowedUsers, { onDelete: 'CASCADE' })
  @JoinColumn({ 
    name: 'terminal_id', 
    foreignKeyConstraintName: 'fk_user_allowed_terminals__app_terminals__terminal_id' 
  })
  terminal: AppTerminal;
}
```

```typescript
// backend/nest-app/src/modules/terminals/entities/app-terminal.entity.ts

import { Entity, PrimaryGeneratedColumn, Column, CreateDateColumn, UpdateDateColumn, OneToMany, OneToOne, Index } from 'typeorm';
import { TerminalType } from '../enums/terminal-type.enum';
import { TerminalStatus } from '../enums/terminal-status.enum';
import { UserAllowedTerminal } from '../../auth/entities/user-allowed-terminal.entity';
import { TerminalRights } from './terminal-rights.entity';

@Entity('app_terminals')
@Index('uq_app_terminals__terminal_id', ['terminalId'], { unique: true })
@Index('ix_app_terminals__type', ['type'])
@Index('ix_app_terminals__status', ['status'])
export class AppTerminal {
  @PrimaryGeneratedColumn('uuid', { name: 'id' })
  id: string;

  @Column({ type: 'varchar', length: 255, unique: true, name: 'terminal_id' })
  terminalId: string;

  @Column({ type: 'varchar', length: 255, nullable: true, name: 'friendly_name' })
  friendlyName: string | null;

  @Column({
    type: 'enum',
    enum: TerminalType,
    default: TerminalType.WEB,
    name: 'type',
  })
  type: TerminalType;

  @Column({
    type: 'enum',
    enum: TerminalStatus,
    default: TerminalStatus.ACTIVE,
    name: 'status',
  })
  status: TerminalStatus;

  @Column({ type: 'varchar', length: 500, nullable: true, name: 'user_agent' })
  userAgent: string | null;

  @Column({ type: 'varchar', length: 100, nullable: true, name: 'ip_address' })
  ipAddress: string | null;

  @Column({ type: 'timestamp', nullable: true, name: 'last_seen_at' })
  lastSeenAt: Date | null;

  @CreateDateColumn({ type: 'timestamp', name: 'created_at' })
  createdAt: Date;

  @UpdateDateColumn({ type: 'timestamp', name: 'updated_at' })
  updatedAt: Date;

  // Relations
  @OneToMany(() => UserAllowedTerminal, (uat) => uat.terminal)
  allowedUsers: UserAllowedTerminal[];

  @OneToOne(() => TerminalRights, (rights) => rights.terminal)
  rights: TerminalRights;
}
```

    - **Felder:** `state`, `changed_at`, `last_updated`
    - **Partitionierung:** Nach `changed_at` (Monat)

17. **HaEntityAttribute** (`ha-entity-attribute.entity.ts`)
    - **EAV-Modell**
    - **PK:** UUID (`id`)
    - **FK:** `entity_id` → `HaEntity` (`CASCADE`)
    - **Felder:** `attribute_key`, `attribute_value` (JSONB)
    - **Composite Index:** `(entity_id, attribute_key)`

### Implementierungshinweise

**Natürliche Schlüssel:**
- `HaArea.area_id`, `HaDevice.device_id`, `HaEntity.entity_id` sind STRING-PKs (keine UUID)
- Grund: HomeAssistant verwendet diese IDs als natürliche Keys
- Import-Performance: Direkte Referenzierung ohne UUID-Mapping

**Domain-Extraktion:**
```typescript

  this.objectId = objectId;
}
```

## ⚠️ Risiken & Offene Punkte

### Risiko 1: Fehlende Entity-Specs (14/18)

**Status:** 🟡 Mittel  
**Problem:** Nur 4 detaillierte Specs existieren (User, UserRights, AppTerminal, HaEntity)  
**Mitigation:** 
- Referenz: `DBM-SCHEMA-03-TypeORM-Mapping.md` (Zeilen 200-1500) als Basis
- Bei Unklarheiten: Specs nachholen

### Risiko 2: DB-Wahl nicht finalisiert

**Status:** 🟡 Mittel  
**Problem:** PostgreSQL vs. MariaDB beeinflusst UUID/JSONB-Implementierung  
**Mitigation:**
- TypeORM abstrahiert JSONB → JSON
- UUID-Generierung via TypeORM (DB-agnostisch)
- **Entscheidung fällen vor Migrations-Phase!**

### Risiko 3: Circular Dependencies

**Status:** 🟢 Niedrig  
**Problem:** Bidirektionale Relationen können Circular Imports erzeugen  
**Mitigation:**
- Lazy Loading: `@OneToMany(() => TargetEntity, ...)`
- Forward References in TypeScript

### Risiko 4: Performance (HaEntityState Historie)

**Status:** 🟡 Mittel  
**Problem:** `ha_entity_states` kann Millionen Rows haben  
**Mitigation:**
- Partitionierung (später in Migrations-Phase)
- Indizes auf `entity_id`, `changed_at`
- Retention Policy (später)
